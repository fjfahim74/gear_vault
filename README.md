# GearVault

GearVault is an equipment rental platform that connects equipment owners with customers. Owners can list their equipment for rent, while customers can explore available equipment, make bookings, and complete secure online payments. The platform also provides role-based dashboards for managing equipment, rentals, users, and platform activities.

## ✨ Key Features

### 1. Equipment Marketplace
Browse available equipment with detailed information, including images, categories, rental prices, locations, and availability. Search, filter, and sort equipment to find suitable items.

### 2. Equipment Management
Equipment owners can add new listings, update equipment information, manage their listings, and track rental requests.

### 3. Equipment Booking & Secure Payments
Customers can select rental dates, check availability, calculate rental costs, and book equipment. Secure online payments are processed through Stripe Checkout.

### 4. Role-Based Dashboards
Separate dashboards for Customers, Owners, and Admins provide access to features and management tools based on their roles.

### 5. Customer Dashboard
Customers can view their rentals, manage favorite equipment, track booking statuses, and update their profile information.

### 6. Owner Dashboard
Owners can manage equipment listings, monitor rental requests, track earnings, and view equipment and rental analytics.

### 7. Admin Dashboard
Admins can manage users, update user roles, review and manage equipment listings, monitor rentals, and view platform analytics.

### 8. Authentication & Authorization
Secure authentication with email and password or Google sign-in, supported by Better Auth and JWT-based API authorization. Role-based access control protects private pages and API endpoints.

### 9. Email Notifications
Automated email notifications are sent to customers and equipment owners when a rental is completed.

### 10. Light & Dark Theme
Switch between light and dark themes for a comfortable browsing experience.

### 11. Responsive Interface
A responsive interface provides a consistent experience across mobile, tablet, and desktop devices.

## 📌 Project Purpose

GearVault aims to make equipment rental easier and more accessible by providing a centralized marketplace for equipment owners and customers. It simplifies equipment listing, rental booking, payment processing, and rental management while maintaining a secure and organized platform for all users.
